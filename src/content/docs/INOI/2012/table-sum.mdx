## Abridged statement

A table has two rows and $N$ columns. The first row is given as $a_1, a_2, \ldots, a_N$. The score
of a table is the largest column sum. The second row is filled with a cyclic shift of
$1, 2, \ldots, N$: for shift $k$ it reads $k, k+1, \ldots, N, 1, \ldots, k-1$. Report the score for
each of the $N$ shifts.

$1 \le N \le 200000$, and every entry in the first row is between $1$ and $100000$. The limits are
2 seconds and 32 MB.

## Editorial

### One shift at a time

Fix a shift $k$ and look at column $c$. The top entry is $a_c$, and the bottom entry is the $c$-th
element of the sequence that starts at $k$, so it is $k + c - 1$ while that stays within $N$, and
$k + c - 1 - N$ once it has wrapped around. The score is the largest $a_c + (\text{bottom entry})$
over all $c$.

Computing that directly for every shift is $O(N^2)$, which clears the $N \le 3000$ subtask and
nothing more. We need each shift in roughly constant time.

<details>
<summary>Hint 1</summary>

Ignore the wrapping for a moment. The bottom entry would just be $c + (k-1)$, so the column sum
would be $a_c + c + (k-1)$. The part that depends on the column is $a_c + c$, and the part that
depends on the shift is a constant added to every column.

</details>

<details>
<summary>Hint 2</summary>

Wrapping does not break that, it only splits the columns into two groups. Columns that have not
wrapped get one constant added, columns that have wrapped get a different constant. Both groups
are contiguous.

Which columns are in which group, and how do you take a maximum over each group quickly?

</details>

<details>
<summary>Key idea</summary>

<Aside type="tip" title="Key idea">
Write $g_c = a_c + c$. Every shift is then a prefix maximum of $g$ against a suffix maximum of $g$.
</Aside>

The split point moves by one as $k$ increases, so precomputing prefix and suffix maxima of $g$
answers all $N$ shifts in $O(N)$ total.

</details>

### Splitting at the wrap

For shift $k$, the bottom entry stays in range exactly while $k + c - 1 \le N$, that is
$c \le N - k + 1$. So the columns split into two contiguous groups:

- $c \le N - k + 1$: bottom entry is $k + c - 1$, so the column sum is $g_c + (k-1)$
- $c > N - k + 1$: bottom entry is $k + c - 1 - N$, so the column sum is $g_c + (k - 1 - N)$

Within each group the added amount does not depend on $c$. So the score is

$$
\text{score}(k) = \max \left( (k-1) + \max_{c \, \le \, N-k+1} g_c, \;\; (k-1-N) + \max_{c \, > \, N-k+1} g_c \right)
$$

The first maximum is a prefix maximum of $g$ and the second is a suffix maximum. Precompute both
arrays once and every shift costs $O(1)$.

The second group is empty when $k = 1$, since nothing has wrapped yet. That case needs skipping,
otherwise you read past the end of the suffix array.

### Implementation

```cpp title="table-sum.cpp"
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    const long long NEG = LLONG_MIN / 4;

    vector<long long> g(n + 2);
    for (int c = 1; c <= n; c++) {
        long long a;
        cin >> a;
        g[c] = a + c;
    }

    vector<long long> pre(n + 2, NEG);
    vector<long long> suf(n + 2, NEG);
    for (int c = 1; c <= n; c++) {
        pre[c] = g[c];
        if (pre[c - 1] > pre[c]) {
            pre[c] = pre[c - 1];
        }
    }
    for (int c = n; c >= 1; c--) {
        suf[c] = g[c];
        if (suf[c + 1] > suf[c]) {
            suf[c] = suf[c + 1];
        }
    }

    for (int k = 1; k <= n; k++) {
        long long best = pre[n - k + 1] + (k - 1);
        if (n - k + 2 <= n) {
            long long wrapped = suf[n - k + 2] + (k - 1 - n);
            if (wrapped > best) {
                best = wrapped;
            }
        }
        cout << best;
        if (k < n) {
            cout << ' ';
        }
    }
    cout << '\n';
}
```

Time complexity: $O(N)$ for the two maxima arrays and $O(1)$ per shift. Memory is $O(N)$.

### Worked example

The sample has $N = 4$ and $a = 7, 1, 6, 2$, so $g = 8, 3, 9, 6$. The prefix maxima are
$8, 8, 9, 9$ and the suffix maxima are $9, 9, 9, 6$.

| $k$ | split at | prefix part | wrapped part | score |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 4 | $0 + 9 = 9$ | empty | **9** |
| 2 | 3 | $1 + 9 = 10$ | $-3 + 6 = 3$ | **10** |
| 3 | 2 | $2 + 8 = 10$ | $-2 + 9 = 7$ | **10** |
| 4 | 1 | $3 + 8 = 11$ | $-1 + 9 = 8$ | **11** |

which matches the expected output of `9 10 10 11`.
